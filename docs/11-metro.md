# Справочник метро

> Статус: черновик.

Нужен для фильтра «станция или линия метро» и для подписи «ближайшее метро» в карточке события. Города: Москва и Санкт-Петербург.

## Что храним

| Поле | Пример |
|---|---|
| Город | Москва |
| Линия: название, цвет | Калининская, `#FFCD1C` |
| Станция: название, координаты | Новокосино, 55.745113, 37.864052 |
| Порядок станции на линии | 0 |

Ближайшую станцию к событию считаем сами по координатам, организатор её не вводит. **[?]** Показывать одну ближайшую или все в радиусе 1,5 км.

## Источник данных

Открытый API hh.ru, без ключа (проверено 22.10.2026):

- Москва — `https://api.hh.ru/metro/1`: 22 линии, 453 записи станций (вместе с МЦК и МЦД; пересадочные станции повторяются на каждой линии).
- Санкт-Петербург — `https://api.hh.ru/metro/2`: 6 линий, 75 записей станций.

Для каждой станции есть название, координаты, линия и её цвет.

План: один раз выгрузить данные в файл в репозитории и обновлять вручную при открытии новых станций. От hh.ru в работе приложения не зависим.

## Открытые вопросы

- **[?]** Считать ли МЦК и МЦД метро в фильтре или показывать отдельной группой.
- **[?]** Пересадочные узлы (например, «Охотный Ряд» — «Театральная» — «Площадь Революции»): одна точка в фильтре или отдельные станции.
- **[?]** Можно ли использовать данные hh.ru — проверить условия их API. Запасной источник — OpenStreetMap.
