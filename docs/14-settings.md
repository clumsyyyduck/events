# Профиль и настройки

> Статус: черновик. Помечено **[?]** — то, что ещё нужно решить.

Открывается кнопкой ⚙️ на главном экране.

## Разделы — MVP

| Раздел | Что внутри |
|---|---|
| **Профиль** | Имя, фамилия, фото, номер телефона (через него вход), «Личность подтверждена» — если пройдена проверка |
| **Город** | Город, события которого показываются на карте. По умолчанию — по геопозиции при первом входе |
| **Мои записи** | Предстоящие события, на которые оплачено место: дата, место, статус брони, отмена и возврат по правилу события |
| **История** | Посещённые события (архив). У каждого — ссылка на событие и кнопка «Оставить отзыв», пока отзыв не написан |
| **Мои вопросы** | Вопросы, которые пользователь задал организаторам, и ответы на них |
| **Я организатор** | Мои события (черновики, на модерации, опубликованные, прошедшие), отзывы обо мне, вопросы ко мне, выплаты |
| **Уведомления** | Что присылать: напоминание о событии, ответ на вопрос, отмена события, новый отзыв (для организатора) |
| **Поддержка** | Обращение в поддержку (ИИ, при необходимости — человек), история обращений |
| **Пользовательские настройки** | Приватность (см. ниже), выйти, удалить аккаунт |
| **Документы** | Отдельный раздел, не в пользовательских настройках: пользовательское соглашение, политика обработки персональных данных, правила возврата |

**Мои записи и история** доступны в настройках и дополнительно — кнопкой 📅 на главном экране: туда заходят часто.

**Удалить аккаунт** — обязательно: по закону о персональных данных пользователь вправе отозвать согласие.

## Приватность

Скрыть профиль полностью нельзя. Можно скрыть отдельные данные:

| Кто смотрит | Что видит |
|---|---|
| Организатор события, на которое записан пользователь | Всегда имя и фамилию — нельзя скрыть |
| Другие участники того же события и остальные пользователи | Имя — всегда. Фамилию — если пользователь её не скрыл |

В пользовательских настройках:

- **Скрыть фамилию** от всех, кроме организаторов моих событий.
- **Скрыть историю посещений** — по умолчанию история видна другим пользователям.

**В MVP** открыть можно только профиль организатора. Профили участников, список «Кто идёт» на событии и чужая история посещений — **после MVP**. Настройки приватности (фамилия, история) закладываем сразу, чтобы они были готовы, когда профили участников станут видны.

## Разделы — после MVP

| Раздел | Что внутри |
|---|---|
| **Любимые фильтры** | Сохранённые наборы фильтров («Волейбол по выходным до 1000 ₽») — включаются одним нажатием |
| **Избранное** | Сохранённые события «пойду, если получится» |
| **Подписки на организаторов** | Уведомление, когда любимый организатор публикует новое событие |
| **Уведомления по фильтрам** | «Сообщить, когда появится падел рядом с домом в выходные» |
| **Оформление** | Светлая / тёмная тема |
| **Вход через Telegram** | Привязка второго способа входа |

## Подсказка о смене города

Если по геопозиции пользователь в другом городе из списка — показываем подсказку сменить город (см. [21-map-and-search.md](21-map-and-search.md)). Если пользователь закрыл её, не сменив город, показываем ещё **один** раз, потом больше не показываем — до следующей смены города.

Каждая смена города — новый город: подсказка показывается снова.

**Чтобы не надоедать в дороге:**

- подсказка только при открытии приложения, без push-уведомлений;
- только для городов, где мы работаем — проезд через другие города её не вызывает;
- только если пользователь в новом городе не меньше ~2 часов или открывает приложение там второй раз — так транзит не считается;
- если пользователь дважды закрыл подсказку для одного и того же города, в следующий раз для этого города не предлагаем 30 дней.
