# Профиль и настройки

> Статус: черновик. Помечено **[?]** — то, что ещё нужно решить.

Открывается кнопкой ⚙️ на главном экране.

## Разделы — MVP

| Раздел | Что внутри |
|---|---|
| **Профиль** | Имя, фото, номер телефона (через него вход), «Личность подтверждена» — если пройдена проверка |
| **Город** | Город, события которого показываются на карте. По умолчанию — по геопозиции при первом входе |
| **Мои записи** | Предстоящие события, на которые оплачено место: дата, место, статус брони, отмена и возврат по правилу события |
| **История** | Посещённые события (архив). У каждого — ссылка на событие и кнопка «Оставить отзыв», пока отзыв не написан |
| **Мои вопросы** | Вопросы, которые пользователь задал организаторам, и ответы на них |
| **Я организатор** | Мои события (черновики, на модерации, опубликованные, прошедшие), отзывы обо мне, вопросы ко мне, выплаты |
| **Уведомления** | Что присылать: напоминание о событии, ответ на вопрос, отмена события, новый отзыв (для организатора) |
| **Поддержка** | Обращение в поддержку (ИИ, при необходимости — человек), история обращений |
| **Документы** | Пользовательское соглашение, политика обработки персональных данных, правила возврата |
| **Выйти** | — |
| **Удалить аккаунт** | Удаление профиля и персональных данных. Требуется по закону о персональных данных: пользователь вправе отозвать согласие |

**[?]** «Мои записи» и «История» — внутри настроек или отдельной кнопкой на главном экране (сейчас в демо — отдельная кнопка 📅 «Мои записи»). Предложение: кнопка 📅 открывает записи и историю, в настройках — профиль и всё остальное.

## Разделы — после MVP

| Раздел | Что внутри |
|---|---|
| **Любимые фильтры** | Сохранённые наборы фильтров («Волейбол по выходным до 1000 ₽») — включаются одним нажатием |
| **Избранное** | Сохранённые события «пойду, если получится» |
| **Подписки на организаторов** | Уведомление, когда любимый организатор публикует новое событие |
| **Уведомления по фильтрам** | «Сообщить, когда появится падел рядом с домом в выходные» |
| **Оформление** | Светлая / тёмная тема |
| **Вход через Telegram** | Привязка второго способа входа |
