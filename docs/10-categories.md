# Категории, виды и фильтры

> Статус: черновик. Помечено **[?]** — то, что ещё нужно решить.

## Как устроено

Три уровня:

1. **Категория** — крупная группа, у неё свой цвет на карте: «Спорт», «Танцы».
2. **Вид** — конкретное занятие, у него своя иконка: «Волейбол», «Бег».
3. **Особые поля вида** — то, что важно только для этого вида: уровень игры для волейбола, возраст ребёнка для детских событий.

Организатор при создании события выбирает категорию, затем вид, затем заполняет общие поля и особые поля вида. По этим же полям участник фильтрует события.

**Модерация** (см. [01-vision.md](01-vision.md)) проверяет, что текст и картинки соответствуют выбранной категории, виду и полям.

## Общие поля и фильтры (для всех событий)

| Поле | Значения | Фильтр для участника |
|---|---|---|
| Дата и время | дата, начало, длительность | Сегодня, Завтра, Выходные, Выбрать даты, Время суток (утро, день, вечер) |
| Цена | бесплатно или сумма в рублях | Бесплатно, До 500 ₽, До 1000 ₽, Свой диапазон |
| Места | всего мест, осталось | Есть свободные места |
| Место проведения | адрес, точка на карте, ближайшее метро | Рядом со мной, по карте, станция или линия метро |
| Возрастное ограничение | 0+, 6+, 12+, 16+, 18+ | Скрыть 18+, Подходит детям |
| Можно прийти одному | да / нет | Можно прийти одному |
| Правило возврата | выбирает организатор | — (показывается в карточке) |
| Рейтинг организатора | из отзывов | Рейтинг от 4,5 |

**Юридически проверить:** нужна ли возрастная маркировка (0+ … 18+) для всех событий или только для зрелищных (спектакли, концерты, кино) по закону о защите детей от информации.

## Открытые вопросы

- **Регулярные события — после MVP.** В MVP каждое занятие создаётся отдельно. Позже — повтор («каждый четверг в 19:00»). **[?]** Нужны ли абонементы.
- **[?] Несколько видов у события.** Учитываем. Предложение: один **основной** вид (он задаёт цвет и иконку на карте) и до двух **дополнительных** (событие находится и по их фильтрам). Примеры:
  - «Йога и бранч» — Тело и практики → Йога + Еда → Бранчи;
  - «Сап-йога» — На природе → Сапы + Тело и практики → Йога;
  - «Английский за настолками» — Обучение → Языковые клубы + Игры → Настольные игры;
  - «Фотопрогулка по старой Москве» — Творчество → Фотопрогулки + Культура → Экскурсии;
  - «Пробежка и кофе с нетворкингом» — Спорт → Бег + Обучение и общение → Нетворкинг.
- **[?] «Дети и семья» — категория или признак.** Детское событие почти всегда ещё и что-то другое: детская керамика — это Творчество, детский футбол — Спорт. Возможно, лучше убрать категорию и сделать общий фильтр «Для детей» с полем «возраст ребёнка».
- **[?] Знакомства.** События, цель которых — познакомиться: быстрые свидания, вечеринки для одиноких, «ужин вслепую». Варианты: отдельная категория с пометкой 18+, вид внутри «Обучение и общение» или не публикуем совсем.
- **[?] Абонементы** для повторяющихся событий (после MVP).

## Решено

- **Вида нет в списке.** Организатор обращается в поддержку. Поддержка добавляет вид, если он подходит.
- **Фильтр по метро.** Нужен — для Москвы и Петербурга. Требуется справочник станций и линий.
- **Запрещённые темы.** Обязательно входят в MVP, прорабатываются отдельным документом — [23-moderation-rules.md](23-moderation-rules.md).
